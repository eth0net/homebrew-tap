# homebrew-tap

Homebrew formulae for [eth0net](https://github.com/eth0net)'s tools.

```sh
brew install eth0net/tap/gdck
```

Formulae here are written by [`dist`](https://github.com/axodotdev/cargo-dist)
when a release is tagged in the tool's own repository, so this repository is
generated rather than edited. Report anything wrong with a formula against the
tool it installs.

| Formula | What it is |
|---|---|
| `gdck` | A fast GDScript formatter and linter — [eth0net/gdck](https://github.com/eth0net/gdck) |
